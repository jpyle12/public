## Guides

### [Write Better Jev Questions](guide-write-better-jev-questions.md)

An independent guide to designing better questions for TypeSafe AI's Jev System One model, based in part on what I ran into while building with it.

Includes:
- Before/after examples for `Choice`, `Score`, and `Noul`
- Separating semantic judgments from application policy
- Common failure modes and debugging approaches
- Speculative fan-out and working with coding agents
- Confidence, validation, and model versioning
- A complete Python support-routing example

A practical companion to Allie Laabs's [*Don't Call It a Decision Model*](https://typesafe.ai/blog/dont-call-it-a-decision-model).
